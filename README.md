# 素材下载器

轻量独立工具，直连云数据库查询并批量下载视频素材。

## 使用方法

1. 确保电脑已安装 **Python 3.10+**
2. 双击 `启动下载器.bat`
3. 首次使用填写 Turso URL 和 Token（自动保存到 `config.json`）
4. 选择筛选条件 → 搜索预览 → 下载全部

## 筛选条件

- **剧场** / **语种** / **备注**：下拉选择
- **起始/结束日期**：格式 `YYYY-MM-DD`，可只填一个
- **剧名搜索**：模糊匹配，不填则不筛选

## 下载目录结构

```
下载根目录/
  SM-en-My Dad Is Poseidon-20260425-JX/
    055833accbf4a14f5a6c23a9607105d8.mp4
  SM-zh-某剧名-20260426-DBZ/
    ...
```

缩写规则：
- 剧场：`SM`=ShortMax, 其他取前6字符
- 语种：`zh`=中文, `en`=英文, 等
- 备注：`JX`=精选, `DBZ`=待备注, `WG`=违规

## 依赖

**零额外依赖**，仅需 Python 标准库（tkinter + urllib）。
